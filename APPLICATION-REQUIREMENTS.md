# taskManager

**Created:** 2026-02-15 12:44:48.361404
**Type:** web

---

Build a task management application with these features: PAGES NEEDED: - Dashboard: Overview of all tasks with statistics - Tasks List: Filterable list (pending/completed/all) - Task Detail: View/edit individual task - Settings: User preferences FEATURES: - Create, edit, delete tasks - Each task has: title, description, due date, priority (high/medium/low), status - Filter by status and priority - Sort by due date or priority - Search functionality - Statistics: total tasks, completed %, overdue count - Dark mode toggle UI STYLE: - Modern, clean design - Use blue/indigo color scheme - Card-based layout for tasks - Responsive (mobile-friendly)
